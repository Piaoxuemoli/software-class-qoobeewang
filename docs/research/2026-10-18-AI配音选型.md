# AI 配音选型调研（开源声音克隆）

> 用途：为 DataBackup 演示视频（≤3 分钟、中文技术旁白）选择开源 TTS/声音克隆方案。
> 约束：用户可提供 **≤100s** 的本人声音样本；可租 **8–24GB** 显存 GPU；课程演示属非商业用途；部署尽量不折腾。
> 结论基于 2026-10 的公开资料与社区实测；标注「待验证」的项须在 P1 部署时实测确认。

## 1. 结论

**首选：GPT-SoVITS v4（少样本微调）**
- 代码 MIT；1 分钟数据即可训练；中文自然度与韵律在开源里第一梯队；6GB 显存可推理，8–12GB 可训练；有 WebUI 与 Windows 整合包。
- 代价：要准备带转写的 60–100s 数据并跑一次微调（约 10–30 分钟），比"零样本"多一步；这一步对 3 分钟成片的音色稳定性值得。

**备选（不想训练）：IndexTTS2 / CosyVoice2**
- IndexTTS2：单段参考音频零样本克隆，约 6GB 显存，支持情感控制（时长控制因版本而异）；权重许可为 bilibili 模型协议（非商业，课程可用）。
- CosyVoice2/3：代码 Apache-2.0，3–10s 参考音频零样本，中文强，实测约 7–8GB 显存；有官方示例与 vLLM 加速。

**保底：F5-TTS / Fish Speech**
- F5-TTS：代码 MIT、权重 CC-BY-NC；推理仅 2–3GB（社区实测），10–15s 参考；速度快，但中文多音字/长句偶有吞字，需要逐句试听。
- Fish Speech 1.5：代码 Apache-2.0、权重 CC-BY-NC-SA-4.0；≥4GB 显存，10–30s 参考，中英混合好；中文韵律略逊于 GPT-SoVITS。

**不建议**：XTTS-v2（权重 CPML 非商业、仓库已停更、中文一般）、OpenVoice V2（音色克隆为主、长句韵律弱）。

### 决策树

```text
有时间跑一次微调（1–2h）？
├─ 是 → GPT-SoVITS v4（首选）
└─ 否 → 只想给一段参考音频就出音？
        ├─ 显存 ≥8GB 且要中文自然 → CosyVoice2/3
        ├─ 显存 6GB、要简单 → IndexTTS2
        └─ 显存 ≤6GB 或想最快跑通 → F5-TTS（逐句听，吞字就重生成）
```

## 2. 需求与约束

| 维度 | 要求 |
|---|---|
| 语言 | 中文技术旁白，含 `Huffman`、`AES-256`、`.dbk`、`Linux` 等英文/数字 |
| 参考音频 | 用户本人 ≤100s；安静环境、单人、无背景音乐 |
| 时长 | 逐句生成，总旁白约 77s（7 段），单句 8–16s |
| 显存 | 8–24GB 可租；不要几十 GB 的卡 |
| 控制 | 语速可调（0.95–1.05）、句间停顿可控、长句不崩 |
| 许可 | 课程演示非商业；优先 MIT/Apache，CC-BY-NC 可接受 |
| 部署 | Linux + NVIDIA 优先；Windows/WSL 也可 |
| 输出 | 24kHz 或 44.1kHz WAV，便于 ffmpeg 对齐 |

## 4. 逐项评估

### 4.1 GPT-SoVITS v4（推荐）

- **能力**：1 分钟语音数据即可微调出可用音色；中文断句、多音字、语气词处理在开源里属第一梯队；据 v4 发布说明，它修复了 v3 的非整数倍上采样金属音问题。
- **两条路径**：
  1. **零样本**：给 5–10s 参考音频 + 参考文本，直接推理，先验证音色；
  2. **微调**：把 60–100s 切成 3–10s 片段，ASR 转写后训练 SoVITS + GPT，音色更稳、长句更自然。
- **显存**：推理 6GB 够用（社区用 RTX 2060 6G 跑通）；微调建议 8–12GB。
- **部署**：官方 WebUI + Windows 整合包；Linux 用 conda + `requirements.txt` + 预训练权重。
- **风险**：WebUI 版本迭代快，依赖 torch/ffmpeg；数据转写要用准确文本（英文术语、数字必须手改）。

### 4.2 IndexTTS2（备选，最省训练）

- **能力**：单段参考音频零样本克隆，支持情感控制（时长控制因版本而异）；社区评价中文自然度接近 GPT-SoVITS，适合"不想训练"的路线。
- **显存**：约 6GB（官方/第三方推理包数据）。
- **许可**：bilibili 模型使用协议，非商业课程演示可用；不要用于商业分发。
- **风险**：协议条款要读一遍；权重下载体积较大；推理代码版本较新，依赖 Python 3.10–3.11。

### 4.3 CosyVoice2 / CosyVoice3

- **能力**：3–10s 参考音频零样本；中文/英文/方言；流式推理，适合长文本；CosyVoice3 支持更多语言与指令控制。
- **显存**：实测 7.2–7.6GB（600 字文本），8GB 更从容，6GB 是门槛。
- **许可**：代码 Apache-2.0；权重以模型页为准。
- **风险**：官方仓库结构变动（QwenAudio/CosyVoice），老教程路径可能失效；vLLM 需要计算能力 7.0+。

### 4.4 F5-TTS（保底）

- **能力**：Flow Matching，零样本克隆，推理快；社区实测 2–3GB 显存。
- **问题**：中文长句偶发吞字/重复；参考音频质量影响大；权重 CC-BY-NC 仅非商业。
- **适用**：先用它 30 分钟跑通"样本→声音"，验证流程与字幕时长，再决定是否上 GPT-SoVITS。

### 4.5 Fish Speech 1.5

- **能力**：10–30s 参考，中文/英文/日文；≥4GB 显存；Docker/CLI 部署简单。
- **许可**：代码 Apache-2.0，权重 CC-BY-NC-SA-4.0；课程可用。
- **风险**：中文韵律与多音字不如 GPT-SoVITS；长句需要分段。

### 4.6 Spark-TTS / MegaTTS3 / XTTS-v2（可选/不推荐）

- Spark-TTS：0.5B LLM 方案，3s 参考；12GB 实测，8GB 待验证；生态较新。
- MegaTTS3：字节系，3–5s 参考；4GB 起、8GB 推荐；中文可用，资料相对少。
- XTTS-v2：Coqui 已停更，权重 CPML 非商业，中文一般；只在"已有现成环境"时考虑。

## 5. 推荐部署路线（GPT-SoVITS v4）

### 5.1 机器与系统

- Ubuntu 22.04/24.04 + NVIDIA 驱动（CUDA 12.x）；显存 ≥8GB（训练）/≥6GB（只推理）。
- 磁盘 ≥40GB（权重 + 数据集 + 输出）；Python 3.10。

### 5.2 最小命令（Linux）

```bash
git clone https://github.com/RVC-Boss/GPT-SoVITS.git
cd GPT-SoVITS
conda create -n gsv python=3.10 -y && conda activate gsv
pip install -r requirements.txt
# 按 README 下载 pretrained_models（GPT/SoVITS 底模、中文 ASR、uvr5 可选）
python webui.py --port 9874
```

> 也可以用官方 Windows 整合包（解压即用）在租用机的 Windows 镜像里跑；或社区 Docker 镜像。P1 以"能跑通推理"为准，不纠结路线。

### 5.3 零样本先验证

1. 上传 5–10s 参考音频 + 对应文本；
2. 合成 3 句测试文本（含数字、`Huffman`、`AES-256`）；
3. 听：音色像不像、有没有吞字、语速是否合适；
4. 不满意再走微调。

### 5.4 微调（推荐）

1. 样本切分：3–10s/段，静音切除，总时长 60–100s；
2. ASR 转写：中文用项目自带 ASR，英文术语/数字手工校正；
3. 训练 SoVITS（约 8–20 分钟/8GB）→ 训练 GPT（约 10–30 分钟）；
4. 用同一批测试句对比零样本 vs 微调，选更稳的。

### 5.5 P1 试听文本（固定这三句，方便横向对比模型）

1. `DataBackup 把 Linux 目录树备份成一个文件，并原样还原。`
2. `压缩使用 Huffman 编码，加密使用 AES-256，口令只经标准输入传递。`
3. `本次备份一万个文件，耗时 0.16 秒，压缩率 0.616。`

验收：三句都不吞字；`AES-256` 读作 "A-E-S 二五六" 或 "AES 二百五十六" 均可，但整片必须一致；`0.616` 读作 "零点六一六"。

### 5.6 常见问题与规避

| 问题 | 处理 |
|---|---|
| HuggingFace 下载慢/失败 | 设置 `HF_ENDPOINT=https://hf-mirror.com`；或从 ModelScope 下载同名权重 |
| CUDA/torch 版本不匹配 | 按项目 README 的 torch 版本装；不要混用系统 CUDA 与 conda 包 |
| 缺少 ffmpeg | GPT-SoVITS/ASR 依赖 ffmpeg；Ubuntu `apt install ffmpeg`，或下载便携版 |
| 生成有电流/金属音 | 换参考音频片段（更干净），或走微调；F5/Fish 可调 temperature |
| 长句吞字 | 按标点拆句，单句 ≤20 字；不要一次生成整段 |
| 音色漂移 | 固定参考音频与随机种子；每句用同一参考 |
| 显存不够 | 降 batch、关 vLLM；F5/IndexTTS 6GB 可跑，CosyVoice 需 8GB |
| 声音太"播音腔" | 参考样本用自然语速、日常语气；TTS 语速 0.98，别拉满 |

## 6. 声音样本准备清单（给用户）

- **时长**：60–100s（不少于 30s；100s 足够微调）。
- **格式**：WAV，24kHz 或 44.1kHz，16bit，单声道；不要 MP3 转码多次。
- **环境**：安静房间、无回声、无背景音乐/风扇声；手机录音也可以，但离麦 15–20cm。
- **内容**：正常语速朗读一段技术文字，覆盖：
  - 中文陈述句、疑问句；
  - 数字：`2026`、`10,000`、`0.616`；
  - 英文术语：`Huffman`、`AES-256`、`Linux`、`.dbk`；
  - 标点停顿：逗号、句号、冒号。
- **一致性**：同一支麦、同一距离、同一音量；不要中途换房间。
- **授权**：仅本人声音；样本与模型输出只放 `course/`（gitignore），不上传公共模型库。

## 7. 生成、对齐与验收

### 7.1 逐句生成

- 按分镜的 7 段旁白逐句生成，文件名 `s0.wav`…`s6.wav`。
- TTS 参数：语速 0.98–1.05（以 4.2–4.6 汉字/秒为准）；句末停顿 200–400ms。
- 每句 `ffprobe` 记录时长，写入 `voice/manifest.json`（文本、时长、参数）。

### 7.2 验收

| 检查 | 方法 | 通过线 |
|---|---|---|
| 可懂度 | 用 Whisper/faster-whisper 回译，与原文算 CER/WER | 中文 CER <5%；英文术语不读错 |
| 音色 | 与样本 A/B 盲听 | 3 人里 2 人认为同一人（自评即可） |
| 自然度 | 逐句听 | 无吞字、无重复、无金属音 |
| 节奏 | 与分镜时长对比 | 单句误差 ≤15%，总旁白 ≤80s |
| 数字/术语 | 人工核对 | `AES-256` 不读成" AES 二百五十六"之类 |

### 7.3 失败处理

- 吞字/重复：拆句、加标点、换参考音频片段，仍不行换模型（IndexTTS2/CosyVoice2）。
- 音色不像：增加参考音频到 30–60s，或走微调。
- 语速不对：TTS 语速参数 ±5%，不要后期变速（会改变音色）。

## 8. 成本与时间估算

| 阶段 | 时间 | 显存 |
|---|---|---|
| 环境 + 权重下载 | 30–60 分钟 | — |
| 零样本试听 | 15 分钟 | 6–8GB |
| 微调（可选） | 30–60 分钟 | 8–12GB |
| 7 句生成 + 验收 | 30 分钟 | 6–8GB |
| 合计 | 约 2 小时（含调试） | 8–12GB 单卡足够 |

> 租一张 RTX 4090 24GB 最省心；RTX 3060 12GB 也能完成（微调慢一些）。不需要 A100/H100。

## 9. 风险与合规

- **声音授权**：只用本人样本；产出仅课程使用；不公开模型权重与样本。
- **许可证**：GPT-SoVITS MIT、CosyVoice Apache 最宽松；F5/Fish 权重为非商业，课程演示可用但要在文档注明。
- **平台条款**：上传 B 站时，视频里的 AI 配音是否需要标注，按平台与课程要求处理；建议片尾注明"旁白由 AI 声音克隆生成"。
- **可复现**：记录模型名、commit/版本、权重来源、推理参数、随机种子；写进 `docs/plans/video-phase1.md`。
- **数据安全**：GPU 租用机只放样本与模型，不 clone 整个仓库；完成后删除样本副本。
