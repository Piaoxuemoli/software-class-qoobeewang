## P3 扩展功能：算法自研，不用第三方库实现

引导句：基础备份/还原之外，扩展项都在后端自己实现。界面框架不参与备份逻辑。

| 扩展 | 实现 | 第三方库 |
|---|---|---|
| 文件类型与元数据 | `lstat` 采集，按类型重建 | 不用 |
| 六维过滤 | 自研 `filter`：路径、类型、名字、时间、尺寸、用户组 | 不用 |
| 打包 | 自研 MyPack，512 字节定长头 | 不用 |
| 压缩 | 自研 Huffman，1 MiB 分块 | 不用 |
| 加密 | 自研 AES-256-CBC，PBKDF2-HMAC-SHA256 派生，HMAC | 不用 |
| 图形界面 | Electron + React，只 spawn CLI | 界面框架不实现扩展算法 |

`scripts/check-imports.sh` 会拦住 `archive/*`、`compress/*`、`crypto/aes` 等导入。实时备份和网络备份没有做。
