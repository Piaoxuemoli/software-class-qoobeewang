## P5 数据流水线

scan（遍历 + 过滤）→ pack（MyPack → Huffman → AES-256-CBC+HMAC）→ `.partial` → fsync → 原子改名发布；还原先**整文件校验**再落盘。
【图】seq-backup.puml

## P6 关键技术一：自研 MyPack 归档格式

512 字节小端头记录（仿 tar）、CRC-32、长路径扩展块、双零块结尾；全部 7 种文件类型 + 纳秒时间。
安全：Reader 拒绝绝对路径 / `..` / 软链接下路径 / 越界硬链接（FuzzReader 488 万次执行不崩溃）。

## P7 关键技术二：自研 Huffman 压缩

1MiB 分块流式规范 Huffman（码长表入块头），内存恒定；实测 512MB 文本压缩率 **0.616**、吞吐 ≈97MB/s。

## P8 关键技术三：手写加密栈

SHA-256 → HMAC → PBKDF2（214ms 派生）→ AES-256-CBC + PKCS#7，全部手写并通过公开向量（FIPS-197、RFC 7914/NIST）；容器 encrypt-then-MAC，篡改任一字节 / 错误口令必被检出。
