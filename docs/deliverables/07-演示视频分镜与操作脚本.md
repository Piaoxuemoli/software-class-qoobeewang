# 演示视频分镜与操作脚本

> 面向：录制 DataBackup 课程演示视频（≤3 分钟）。配套文档：
> [06-演示视频脚本](06-演示视频脚本.md)（旧版时长/清单）、[AI 配音选型](../research/2026-10-18-AI配音选型.md)、[视频任务交接](../project/video-handoff.md)。
> 目标成片：**1920×1080 / 30fps / H.264 + AAC / ≤180s**，真实客户端 + 真实后端 v1.0.1，操作可复现。

## 1. 设计原则

1. **分段录制、分段配音、最后拼接**：每段独立起应用、独立预置数据，一段不满意只重录这一段。
2. **操作慢于讲解**：鼠标移动 0.5–0.8s、点击前停留 0.4s、状态变化后停留 0.8s；不做"瞬间跳转"。
3. **字幕与旁白不重复堆叠**：字幕是旁白的压缩版（每屏 ≤2 行、每行 ≤18 字），关键术语才上注解。
4. **所有数值来自真实运行**：文件数、输出大小、压缩率随录制环境略有漂移，字幕不写死具体数字，只写"约"或由后期读取实际值。
5. **不出现**：学号、真实口令、API Key、仓库外的个人目录。

## 6. 注解与字幕规范

- **安全区**：左右各留 80px、底部留 120px（避开字幕与播放器控件）；注解不得遮挡当前操作控件。
- **字幕**：底部居中，字号 34–38px（1080p），白字 + 60% 黑底描边/阴影，单行 ≤18 字，最多 2 行。
- **注解**：深绿色（`#14584B`）圆角框 + 白字标签，字号 24–28px；箭头只指向控件中心，不压住文字。
- **时长**：每条字幕 2.4–4.5s；注解 2.5–3.5s；不叠加超过 2 个注解。
- **字体**：微软雅黑 / Noto Sans CJK；等宽用 JetBrains Mono 或 Consolas。

## 7. 录制与合成流程

### 7.1 分段录制（每段一个文件）

```text
seg-00-title   8s   静态卡（HTML → PNG/视频）
seg-01-data    20s  终端卡（逐行）
seg-02-setup   37s  客户端：S2 操作
seg-03-backup  30s  客户端：S3 操作
seg-04-manage  25s  客户端：S4 操作
seg-05-restore 35s  客户端：S5 操作
seg-06-verify  25s  终端卡 + 片尾
```

- 客户端段用 Playwright `_electron.launch({ recordVideo: { dir, size: 1120×720 } })` 录制；每段独立预置 HOME/仓库，脚本见第 8 节。
- 终端/片头卡用 HTML + Edge/Chromium 渲染成 30fps 视频（或 PNG 序列），由后期合成。
- 原始素材统一放 `course/04-视频/work/`（本地，gitignore）。

### 7.2 配音

1. 按第 5 节旁白文本生成逐句 WAV（TTS 方案见调研文档）。
2. 用 `ffprobe` 量每句时长；若与分镜预算差 >15%，调 TTS 语速或改文案。
3. 按分镜时间轴把每句对齐到镜头起点（允许 ±0.3s），句间补静音。
4. 整轨响度归一到 **-16 LUFS**（`loudnorm`），峰值 ≤ -1.5 dBFS。

### 7.3 合成

```bash
# 每段：缩放/补黑边到 1920×1080、30fps、烧字幕与注解（ASS）、混音
ffmpeg -i seg-02.webm -i seg-02.wav \
  -vf "scale=1680:1080:flags=lanczos,pad=1920:1080:120:0:black,ass=seg-02.ass,fps=30" \
  -c:v libx264 -crf 18 -preset slow -c:a aac -b:a 192k -shortest seg-02.mp4
# 拼接（硬切，段间 0.2s 黑场由 ASS/片尾处理）
printf "file 'seg-00.mp4'\nfile 'seg-01.mp4'\n..." > list.txt
ffmpeg -f concat -safe 0 -i list.txt -c copy -movflags +faststart demo.mp4
```

- ASS 同时承载字幕与注解（`\pos`、`\p1` 画框/箭头），由分镜 JSON 生成；不要用 drawtext 堆命令。
- 段间不加快转场；需要时用 0.2s 淡入淡出，保持"技术演示"的克制。
- 最终检查：`ffprobe` 时长 ≤180s、1920×1080、30fps、音轨存在、无黑帧/静音异常。
