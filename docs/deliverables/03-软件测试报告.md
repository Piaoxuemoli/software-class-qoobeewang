# 软件测试报告

> 负责任务：M8-1 ~ M8-4。课程要求：≥2 种测试类型、≥15 个测试用例；本报告收录 24 张代表性用例表（全部用例编号内嵌于测试代码，可直接检索，见 `docs/conventions/testing.md` §3），另附覆盖率、静态检查、性能与健壮性证据。
> 程序版本：v0.1.0（master `a84bb18`）；除特别注明外，数据实测于 2026-10-16 ~ 2026-10-17。

## 1. 引言

### 1.1 测试目的与范围

验证 DataBackup v0.1.0 对需求说明书 FR-01 ~ FR-18 全部功能需求的实现正确性、健壮性与性能，覆盖后端 CLI、核心库与 Electron 客户端三层。

### 1.2 测试环境

| 项 | 值 |
|---|---|
| 操作系统 | Ubuntu 22.04（Docker 开发镜像 / GitHub Actions runner，root）；Ubuntu 24.04（WSL2，非 root，演示环境） |
| Go / Node | go1.27.1 / Node.js 22.23.3（`scripts/install-deps.sh` 锁定，SHA256 校验） |
| 测试工具 | go test（单元/集成/竞态/fuzz/bench）、testscript（CLI 黑盒）、Vitest（客户端单测）、Playwright（端到端 + 界面截图回归）、staticcheck 2026.2.1、go vet、ESLint、pprof |
| 运行方式 | `make check`（单元+集成+客户端单测+静态检查）/ `make check-all`（另含 race、两端 e2e）/ CI 与本地等价 |

### 1.3 测试类型与规模

共 8 种测试类型（远超课程 ≥2 种要求）；测试代码内嵌用例编号 **400+** 个（`TC-<模块>-<序号>`，全局可检索）。分布：单元（crypto/pack/huffman/filter/walk/fsmeta/container/repo/config）、集成（engine 流水线）、CLI 黑盒（testscript txtar + 组合矩阵）、端到端（真实二进制 SIGTERM 取消、Electron 真实后端链路）、界面回归（截图基线）、fuzz、性能（benchmark + pprof）、竞态（race）。本报告 §2/§5 按模板字段收录代表性用例 24 例。
