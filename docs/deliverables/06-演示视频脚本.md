# 演示视频脚本（M9-4）

> 目标：≤3 分钟完整演示"过滤 + 压缩 + 加密"备份与还原全链路。**执行稿（分镜/旁白/操作/QC）见 [07-演示视频分镜与操作脚本](07-演示视频分镜与操作脚本.md)**；录制改为 Playwright 分段录制 + AI 配音 + ffmpeg 合成。
> 上传取得链接后填入 M9-6 提交包材料（H6）。

## 时长分配（总计 ≤180s）

| 段落 | 时长 | 内容 |
|---|---|---|
| 0 开场 | 0:00~0:10 | 标题画面：项目名 + 一句话定位（"Linux 下把目录树备份为单个加密备份文件并原样还原"） |
| 1 准备 | 0:10~0:30 | 展示源目录树（终端 `tree`/`ls -R`：普通文件、子目录、node_modules、软/硬链接、FIFO）与备份仓库（空） |
| 2 界面编排 | 0:30~1:05 | 打开 DataBackup 客户端：选源目录 → 设备份名 → 添加排除目录 node_modules → 打开压缩、加密 → 输入口令 |
| 3 备份执行 | 1:05~1:30 | 点击开始备份：进度卡实时滚动（文件数/数据量/百分比）→ 完成卡（统计：文件/目录/数据量/输出/压缩率） |
| 4 管理与还原 | 1:30~2:20 | 备份管理页：列表出现新条目 → 详情 → 还原到新目录 → 口令对话框（先输错一次展示"还可尝试 2 次"，再输对）→ 还原完成 |
| 5 验证 | 2:20~2:45 | 终端 `diff -r` 源与还原目录（排除目录除外）无输出；`ls` 仓库出现单个 `.dbk` 文件 |
| 6 收尾 | 2:45~3:00 | 定格：仓库文件 + 测试数据字幕（400+ 用例 / 32 组合矩阵 / 核心包覆盖率 ≥87%） |

## 录制清单（逐项打勾）

- [ ] WSL 内运行 `diff -r` 所需的源目录已预置（建议：~/demo/src，含 node_modules、软链接、FIFO：`mkfifo`）
- [ ] 客户端已按 `docs/client/wsl-guide.md` 安装（deb 或 AppImage 均可），提前启动一次确认 WSLg 出窗
- [ ] 还原目标目录为空目录（后端要求目标不存在或为空）
- [ ] 错误口令演示只用 1 次（第 2 次起界面回编辑态）
- [ ] 录屏分辨率 ≥1080p、帧率 ≥24；鼠标操作放慢，关键按钮停留 1s
- [ ] 口令使用演示专用口令（勿用真实常用口令）
- [ ] 片头/片尾字幕（项目名、组长：王科瑾）
- [ ] 导出后核对：总时长 ≤3:00；上传取得链接（B 站/学校平台），填入 M9-6
