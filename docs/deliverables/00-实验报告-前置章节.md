# 一、实验室名称

信息与软件工程学院实验室（以课程课件标注为准）

# 二、实验项目名称

文件备份软件（DataBackup）

# 三、实验目的

1. 掌握软件开发全生命周期过程与方法：按面向对象软件工程方法完成需求分析 → 系统设计 → 编码实现 → 软件测试 → 打包发布的完整流程，产出规范的过程文档与可运行的软件系统。
2. 掌握现代工程化开发环境：Linux 下 Go 编译型后端与 Electron 桌面客户端的跨端协作开发，容器化统一工具链（Docker 开发镜像、make、Git 分支与 CI 门禁、GitHub Actions）。
3. 掌握备份领域关键技术并自研实现：目录树遍历与过滤、自研归档格式（MyPack）、Huffman 压缩、AES-256 加密（全部手写，不使用现成库）。
4. 实践 AI 辅助开发：以多编码 agent 并行分工的方式完成开发任务，并对 AI 产出建立审查与质量门禁。

# 四、实验内容

**基础要求（40 分）**：数据备份——将目录树中的文件数据保存到指定位置；数据还原——恢复到指定位置。

**扩展要求**（以课件 5/6 新版为准，各扩展项计分见 `docs/project/course-requirements.md` §2.2）：

| 扩展项 | 分值 | 本组选择 |
|---|---|---|
| 文件类型支持（管道/软链接/硬链接/设备等） | 10 | ✅ FR-03：普通文件、目录、软链接、硬链接、FIFO、字符/块设备、套接字共 7 种 |
| 元数据支持（属主/时间/权限等） | 10 | ✅ FR-04：权限位（含 setuid/setgid/sticky）、uid/gid、纳秒级 atime/mtime |
| 自定义备份（路径/类型/名字/时间/尺寸 各 5 分） | 5×5 | ✅ FR-05~09 全做；另实现旧版要求的用户/组过滤（FR-10） |
| 打包解包 | 10 | ✅ FR-11：自研 MyPack 归档格式（512 字节头记录，仿 tar） |
| 压缩解压 | 10 | ✅ FR-12：自研 Huffman 编码（1MiB 分块流式） |
| 加密解密 | 10 | ✅ FR-13：手写 PBKDF2-HMAC-SHA256 + AES-256-CBC + HMAC 校验 |
| 图形界面 | 10 | ✅ FR-16：Electron + React 桌面客户端（备份/管理/设置三页） |

另实现支撑功能：备份仓库管理（FR-14）、配置（FR-15）、安全健壮性（FR-17：完整性校验、路径穿越防护、错误口令识别）、进度与日志（FR-18：JSON Lines 协议实时展示）。功能需求清单详见 `01-需求分析说明书.md` §2，FR-01~18 全部实现。

# 五、实验器材（设备、元器件）

PC 多台，可连接互联网。开发环境：

- 开发主机：Windows 11 + Git Bash + Docker Desktop（统一开发镜像 `databackup-dev`：Ubuntu 22.04 + go1.27.1 + Node.js 22.23.3 + staticcheck 2026.2.1，版本锁定并 SHA256 校验，`scripts/install-deps.sh` 一键复现）。
- 运行/演示环境：WSL2 Ubuntu 24.04 + WSLg（图形客户端演示）；CI：GitHub Actions（Ubuntu 22.04）。
- 版本管理与质量门禁：Git 分支 + PR、make check / check-all、Playwright 截图回归基线。
