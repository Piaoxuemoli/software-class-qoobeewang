## 4. 已定的制作路线

1. **分段录制**（7 段：片头、数据、编排、备份、管理、还原、校验/片尾），每段独立预置数据，最后拼接。
2. **AI 配音**：按调研文档选定方案（默认 IndexTTS-2.5 零样本；愿意训练用 GPT-SoVITS 用满 100s），逐句生成 WAV；用 `ffprobe` 测时长，按分镜时间轴对齐。
3. **字幕/注解**：用 ASS 统一承载，按分镜 JSON 生成，ffmpeg 烧录；不用 drawtext 堆命令。
4. **合成**：每段 scale/pad 到 1920×1080、30fps、混音、烧 ASS；concat 拼接；响度 -16 LUFS。
5. **质量控制**：逐段过清单再拼接，最后全片通看两遍（画面一遍、闭眼听一遍）。

详细分镜、时间轴、操作伪代码、QC 清单见 [07-演示视频分镜与操作脚本](../deliverables/07-演示视频分镜与操作脚本.md)；机器可读时间轴见 [video-storyboard.json](../deliverables/video-storyboard.json)（7 镜、180s、字幕/注解时间点）。

## 7. 风险与注意事项

- **声音克隆授权**：只使用用户本人样本；样本与模型产物放 `course/`（gitignore），不要入库或上传到公共模型库。
- **模型许可**：选 MIT/Apache/CC-BY-NC 等可演示的权重；商用限制不影响课程，但要在调研文档注明。
- **显存/成本**：优先 8–16GB 可跑的方案；一次租用完成 P1/P4，不要反复开关机。
- **GPU 与仓库分离**：训练/推理在租用机器上做，只把生成的 WAV 拉回本地；不要把仓库或样本上传到不确定的第三方盘。
- **字幕同步**：先有音频再到时间轴，禁止"先剪画面再硬塞旁白"；每句误差 >0.5s 就重做该句。
- **数据漂移**：完成卡数字随环境微漂，字幕不要写死字节数；需要时后期读取实际值。
- **版本**：界面状态栏必须是 1.0.1；不要用 v1.0.0 的旧截图或旧产物。
- **长视频质量**：用户明确担心长视频质量——坚持"分段过门禁再拼接"，不要一口气录 3 分钟。
