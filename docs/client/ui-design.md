# 客户端视觉与界面规范

> 风格目标：Grok 式"安静的工具"——纯黑画布、单色界面、白色即强调、一个居中的主任务。依据见 `../research/2026-10-调研报告.md` §4。交互与时序见 `interaction.md`。

## 1. 原则

1. **一屏一个主任务**：备份页只有一个居中的"备份编排卡"，其余信息退到低对比度的次要位置。
2. **单色**：黑、灰阶、白。白色是唯一强调色（主按钮、激活态、焦点）。彩色只用于状态：成功绿、错误红、警告琥珀，且只出现在小面积图标/徽标上。
3. **克制的动效**：动效用于"状态变化"而不是装饰——开始、进度、完成、出错。时长 150~250ms，`ease-out`。尊重 `prefers-reduced-motion`，并在设置里提供"减少动效"。
4. **没有原生感**：无系统标题栏、无系统菜单栏、无默认滚动条样式、无默认焦点框。
5. **数字与路径用等宽字体**，数字使用 tabular-nums，进度跳动时不抖。

## 3. 窗口外框

- `BrowserWindow({ frame: false, backgroundColor: '#000000', show: false, minWidth: 960, minHeight: 640, width: 1120, height: 720 })`，`ready-to-show` 后再显示，避免白屏闪烁。
- 自绘标题栏，高 40px，整条为拖拽区（`-webkit-app-region: drag`），交互元素设为 `no-drag`：
  - 左：应用标识（单色字标 "DataBackup"，`--text-2`）。
  - 中：当前页面名（`--text-3`，13px）。
  - 右：最小化 / 最大化（还原）/ 关闭三个按钮，46×40，线性单色图标（lucide `Minus`、`Square`/`Copy`、`X`），悬停底色 `--surface-2`，关闭按钮悬停 `--danger` 底 + 白色图标。
  - 双击拖拽区切换最大化；最大化状态由主进程事件同步到图标。
- 窗口四周 1px `--border` 描边，让黑色窗口在深色桌面上也有边界。
- 自定义滚动条：6px、`--surface-3` 滑块、无轨道。

## 5. 页面

### 5.1 备份（首页）

空闲态：居中的"备份编排卡"（类似 Grok 首页的输入框）：

1. **源目录**：大号路径输入框 + "选择目录"按钮，支持拖入文件夹；校验存在且可读。
2. **筛选胶囊行**：`类型` `时间` `大小` `用户/组` `名称` `排除目录` 六个胶囊（对应课程参考界面 6 个子页）。点击弹出 Popover 编辑；已设置的胶囊变为白底黑字并显示摘要（如"类型 · 3 项"），带 × 清除。
3. **选项行**：`压缩`开关（Huffman）、`加密`开关（开启后展开口令 + 确认口令，带强度提示）、可选备份名称。
4. **预览行**：`将备份 1,234 个文件 · 2.31 GB`（`--dry-run` 实时计算，见 interaction.md）。
5. **主按钮**：白色胶囊"开始备份"，条件不满足时禁用并在悬停提示原因。

运行态：编排卡原位"变形"为进度卡（共享布局动画）：状态图标、阶段文字（扫描中 / 备份中）、文件数与字节数滚动计数、细进度条（百分比 + 预计剩余时间）、已用时、可折叠日志、"取消"按钮。

完成态：成功图标 + 摘要（文件数、原始大小、备份大小、压缩率、耗时）+ "查看备份" / "再次备份"。失败态：错误说明 + 建议操作 + "重试"。

### 5.2 备份管理

- 顶部：搜索框 + 刷新按钮 + 仓库路径（等宽字体，可点击打开设置）。
- 列表：名称、大小、时间、徽标（压缩 / 加密）；行悬停高亮；空状态有引导文案与"去备份"按钮。`corrupt: true` 的项显示红色"已损坏"徽标，只提供"删除"。
- 右侧详情面板（选中后滑出）：源目录名、创建时间、文件数、原始/备份大小、算法；操作"还原"、"删除"。
- 还原：Sheet 中选择目标目录（必须不存在或为空，实时校验）→ 若加密弹出口令对话框（课程参考界面同款）→ 进度卡（同备份）。
- 删除：按住确认按钮（hold-to-confirm），避免误删。

### 5.3 设置

备份仓库路径（选择 + 保存，校验可写）、动效（标准 / 减少）、关于（前后端版本、开源许可、"本项目使用 AI 辅助开发"说明）。

## 6. 组件选型

| 用途 | 组件 | 来源 |

| 文件数/字节数滚动 | Counter | React Bits（Components） |

React Bits 组件通过 `npx shadcn@latest add https://reactbits.dev/r/<名称>-TS-TW` 拷入 `client/src/components/reactbits/`，保留文件头来源与许可注释（MIT + Commons Clause，应用内使用合规）。新增组件前先确认依赖（motion / gsap / ogl / three），WebGL 类组件必须可关闭。

## 7. 验收方式

- 结构契约：几何与计算样式断言（Sheet 贴右、对话框居中、遮罩存在、无水平溢出、组件圆角/边框），见 `client/e2e/layout.ts`。
- Playwright 截图对比：整页只保留 3 张空闲态，状态与浮层改用元素截图；在 Docker 开发镜像中生成（字体、窗口尺寸固定）。基线的自动审计（尺寸/背景/内容占比/盖章）与范围约定见 [visual-regression.md](visual-regression.md)。
- 交互测试：键盘可完成主流程（Tab 顺序、Enter 提交、Esc 关闭弹层）。
- 对比度：主文字与背景 ≥ 7:1，次要文字 ≥ 4.5:1。
