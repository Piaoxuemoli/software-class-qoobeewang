# UI 打磨调研与方案（提案：任务 C5）

> 状态：提案。本文是 `ui-design.md` 的增量修订稿，**不是推翻**：黑白灰骨架、单色原则、"一屏一个主任务"全部保留，只精修质感。合入后由实现 PR 把令牌表同步回 `ui-design.md` §2。
>
> 输入：7 张现有截图基线（`client/e2e/app.spec.ts-snapshots/`）、`ui-design.md`、`interaction.md`；外部参照见 §2。

## 1. 现状诊断（对照截图基线）

| 问题 | 依据 |
|---|---|
| 纯黑 `#000` + 三级灰面明度差太小，卡片"飘"不起来，层次靠脑补 | `page-backup-linux.png`：编排卡与画布几乎融为一体 |
| 圆角偏小且不成体系（8/12/16 混用），嵌套处内外圆角不同心 | 通用法则：外半径 = 内半径 + 间距 |
| 全界面只有白 + 三个小面积状态色，缺少一个"活的"强调色，灰得发闷 | 全部基线 |
| 动效只到"能换页"级别：卡片变形、状态图标形变、胶囊弹出、数字滚动等未做 | `backup-progress/done` 基线是静态替身 |
| 版本号/仓库路径常驻侧栏底部，`0.0.0-mock` 这类字符串是纯噪音 | `page-backup-linux.png` 左下角 |
| 口令对话框焦点环疑似用了琥珀色（`--warning`），破坏"彩色=状态"约定 | `password-dialog-linux.png` |

## 2. 调研结论（外部参照）

| 参照 | 可借鉴点 |
|---|---|
| **Linear / Raycast**（style.gallery、protoLabs 拆解） | 炭黑而非纯黑（L≈0.13）、1px 发丝边框代替阴影、**单一品牌强调色**（Linear indigo `#5E6AD2`）、同圆角规则、过渡 ≤150ms 无弹跳、焦点环 2px 低透明度 |
| **interfaces.dev 速查表** | 同心圆角（outer = inner + padding）；动画从触发元素发源（transform-origin 对准触发点）；深色下用 `rgb(255 255 255 / 0.08)` 1px 描边；减少动效用媒体查询整体包裹 |
| **Grok 网页/桌面版** | 超大居中 composer、chrome 全弱化、hint 文字必须可读——我们方向对，差在"表面缺微光、动效缺形变" |
| **Zed / Cursor / Warp**（开发者工具通例） | 等宽字体做一切机器输出；徽标小而密；状态色可用但面积克制 |

结论：本项目保持 Grok 式单色骨架，向 Linear 借三件事——**发丝边框层次、一个低饱和强调色、同心大圆角**；向 React Bits 借形变动效。

## 3. 令牌修订提案（落地即改 `ui-design.md` §2）

### 3.1 表面与边框

| 令牌 | 现值 | 提案 | 理由 |
|---|---|---|---|
| `--bg` | `#000000` | `#050506` | 保留"近黑"气质，但给表面留出下沉空间（Linear 经验：纯黑让表面层级不可见） |
| `--surface-1` | `#0A0A0A` | `#0D0D0F`（微弱冷调） | 侧栏/卡片与画布可分辨 |
| `--surface-2` | `#141414` | `#17171A` | 输入/悬浮层 |
| `--surface-3` | `#1F1F1F` | `#232327` | 按下/选中 |
| `--border` | `rgb(255 255 255 / 0.08)` | 不变 | 发丝边框基准正确 |
| `--border-strong` | `rgb(255 255 255 / 0.16)` | `rgb(255 255 255 / 0.20)` | 聚焦态拉开一档 |
| 新增 `--glow` | — | `rgb(124 147 255 / 0.35)` | 焦点环外发光、运行态微光（见 3.3） |

### 3.2 同心圆角系统（"边缘尽量圆角"）

规则：**外半径 = 内半径 + 间距**。取基础间距 8px：

| 层级 | 现值 | 提案 | 用在 |
|---|---|---|---|
| 胶囊/开关/徽标 | 9999 | 9999 不变 | 筛选胶囊、开关、徽标 |
| 输入/按钮/表单项 | 8 | **14** | 源目录输入、Popover 内部控件 |
| 卡片/表格容器 | 12 | **22** | 编排卡、进度卡、关于卡（= 内层 14 + 内边距 8） |
| 弹层 | 16 | **20** | Popover、Dialog、Sheet 内部为 14（20 = 14 + 6 内边距） |
| 窗口级 | — | **24** | 标题栏以下整体容器若做内嵌卡，窗口描边外侧圆角 24 |

同时：图标与文字基线对齐、带图标按钮图标侧 padding −2px（interfaces.dev 光学校准）。

### 3.3 强调色（"颜色"诉求的落地）

保持**白色仍是主按钮/唯一高对比强调**，新增一个低饱和强调色承担"活的"细节——推荐方案 A：

| 令牌 | 值 | 用在（且只用在） |
|---|---|---|
| `--accent-tint` | `#7C93FF`（淡靛蓝，Linear 方向） | 焦点环 `--ring`、进度条填充渐变端点、激活胶囊描边、运行态 StatusMark 弧光、链接/可点击路径、当前页侧栏指示点 |

- 状态色不变：`--success #3DD68C` / `--danger #E5484D` / `--warning #F5A524`，仍小面积。
- 对比度：`#7C93FF` on `#050506` ≈ 6.5:1，可做正文级文字但本方案只让它做装饰/焦点，不承担主文字。
- **方案 B（保守）**：不引入 hue，`--ring` 用 `rgb(255 255 255 / 0.4)` + `--glow` 白色版。若评审认为偏离"白色即强调"太远则退回 B。默认按 A 实施，B 留作回退。
- 顺手修 `PasswordDialog` 焦点环：琥珀 → `--ring`（accent-tint），琥珀只留给真正的警告。

### 3.4 其余令牌

- 阴影：弹层在 `0 8px 32px rgba(0,0,0,0.6)` 基础上加 `0 0 0 1px var(--border)` 内描边；卡片仍无阴影（发丝边框哲学）。
- 字号梯度不变；成功摘要大数字 28px + tabular-nums 保留。
- 动效令牌新增 `--spring: { type: "spring", bounce: 0, duration: 0.3 }`（motion），与 `--dur-fast/--dur/--dur-slow` 并存：位移动画用 spring，纯透明度用时长曲线。

## 4. 动效清单（"动效"诉求的落地）

全部用已有 `motion@14` 实现，**不新增依赖**；每条都给出减少动效降级。

| 位置 | 动效 | 参数 | 降级 |
|---|---|---|---|
| 编排卡 → 进度卡 | `LayoutGroup` + `layoutId` 共享变形 | spring bounce 0 / 300ms | 纯淡入淡出 |
| StatusMark | idle 圆点 → 进度弧（stroke-dashoffset）→ 完成 draw-on 对勾 | 对勾 `pathLength` 0→1，400ms，一次 | 直接切换图标 |
| 进度条 | spring 跟随而非 linear | stiffness 170 damping 26 | 直接 set |
| Counter 数字滚动 | 已选型，确认启用 | 300ms | 直接显示 |
| 筛选胶囊 Popover | 从触发胶囊发源弹出（transform-origin） | spring bounce 0 / 200ms | opacity |
| 页面切换 | FadeContent 上移 8px 淡入 | 150ms | opacity |
| Sheet / Dialog | Sheet 右侧滑入；Dialog scale 0.96→1 + fade | 200ms | opacity |
| 成功徽标 | draw-on 对勾 + 一次性 `box-shadow` glow 脉冲（accent-tint） | 600ms 一次，不循环 | 静态 |
| HoldButton 删除 | 按住 1.2s 环形进度填满，松开回落 | 环 spring 回弹 | 改成二次确认 Dialog？否——降级为按住但无动画 |
| Sonner 通知 | 底部滑入 + fade | 200ms | opacity |
| 列表行删除 | 行高坍缩 + 淡出 | 200ms | 直接移除 |
| 空状态 | 文案逐段淡入（stagger 60ms） | 一次 | 直接显示 |
| 可选氛围 | `DarkVeil`/`Noise` WebGL 背景（不透明度 ≤0.15，仅空闲态） | 设置里默认关 | 减少动效/低端机不渲染 |

通用规则：动画 transform-origin 一律对准触发元素；hover 态 ≤100ms；所有跑动效不阻塞交互（输入全程可用）。

## 5. 版本号与信息降噪

| 位置 | 现状 | 提案 |
|---|---|---|
| 侧栏底部 | 任务迷你状态 + 仓库路径 + "后端 v0.0.0-mock" 三行常驻 | 运行时只留迷你进度行；空闲时底部留白。仓库路径已在设置页首卡与"备份管理"顶栏出现，侧栏删除；**版本行删除** |
| 设置页"关于"卡 | 客户端/后端版本两行平铺 | 默认只显示产品名 + "UESTC 课程项目 · 组长：王科瑾 · 本项目使用 AI 辅助开发"；版本号收进"技术信息"折叠区（`<details>` 或 ChevronDown 小箭头，默认收起），mock 字符串（`0.0.0-mock`）在 UI 永不显示 |
| 标题栏 | 只显示页面名 | 不变，不加版本 |

实现注意：`app.versions()` IPC 保留（测试与"技术信息"折叠区用），只是默认不渲染。

## 6. 交互线覆盖清单（实现时逐条走查）

来自 `interaction.md` §3/§4/§6 + 键盘流，全部要在打磨后仍成立：

- [ ] 键盘全流程：Tab 顺序贯通编排卡，Enter 提交，Esc 关弹层，`Ctrl+B` 收侧栏
- [ ] 筛选胶囊：弹编辑 → 已设置变白底摘要+× → 清除回灰；Popover 从胶囊发源弹出
- [ ] dry-run 预览：400ms 防抖、>2s 显"计算中…"、失败态不挡按钮、数字滚动更新
- [ ] 备份主链：开始 → 进度（扫描/打包两阶段文字）→ 成功摘要+双按钮 / 失败错误+建议+重试 / 取消回 Ready 且表单保留
- [ ] 还原：Sheet 目标目录实时校验（不存在或为空）→ 加密弹口令 → `E_AUTH` 抖动+剩余次数（3 次回 Ready）/ `E_PASSWORD_REQUIRED`
- [ ] 管理页：搜索、刷新、行悬停、详情 Sheet、损坏项红徽标只给删除、长按删除
- [ ] 空状态引导"去备份"；侧栏迷你进度跨页面保持；任务运行中关窗弹原生确认
- [ ] 后端不可用：禁用主按钮 + 路径诊断
- [ ] 减少动效 × `prefers-reduced-motion` 叠加生效
- [ ] **文案纠错（C3 联调发现，2026-10-16）**：`FilterCapsules.tsx:298`「排除目录名（每行一条正则）」与契约不符——`--exclude-dir` 接受**路径**（相对源目录，支持子路径；见 `cli-contract.md` §2.1），正则锚定写法如 `^node_modules$` 不生效。改为「排除目录（每行一条路径，相对源目录）」。同文件 `:282`「排除名称（每行一条正则）」对应 `--exclude-name REGEX`，语义正确不动。仅改文案，不动 IPC 与后端。

## 7. 验收线

- **截图基线全量重拍**（Docker 内生成，字体固定）：现有 7 张全部更新 + 新增 `popover-open`、`page-empty`、`backup-failed`、`sidebar-collapsed` 至少 4 张，凑齐"每页空闲/运行/完成/错误 + 关键浮层"。
- vitest：jobStore 状态机用例不变全过；新增"关于卡技术信息折叠"与"版本号不在默认视图"渲染断言。
- Playwright e2e：现有用例对 mock 后端不动；基线更新即通过。
- a11y：主文字对比度 ≥7:1、次要 ≥4.5:1；`--accent-tint` 不用于小字号正文；焦点环可见；aria 标签齐。
- 性能：日志区行数上限截断照旧；dry-run 防抖照旧；WebGL 背景默认关。
